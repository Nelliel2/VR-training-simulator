# Тренажёр «Идентификация опасностей и инструктирование по охране труда» ![Windows](https://img.shields.io/badge/Windows-10/11-blue.svg) ![SteamVR](https://img.shields.io/badge/SteamVR-darkblue.svg) ![Unity](https://img.shields.io/badge/Unity-2022.3.20-lightgrey.svg)
Это VR Тренажёр на движке Unity, предназначенный для пользователей, 
использующих для доступа ПК на операционной системе Windows и очки виртуальной реальности с двумя контроллерами. 
Программа носит обучающий характер. Это программное обеспечение, предназначенное для организации обучения сотрудников технике безопасности. 
Принципиальным отличием VR тренажера является полное погружение в обучающий процесс, с помощью VR оборудования. 

В программе пользователю предлагаются следующие основные игровые функции: 
оценка обстановки и рисков, идентификация опасностей, просмотр наглядных анимаций, отслеживание прогресса. 

Для эксплуатации тренажёра от пользователя требуются базовые навыки использования ПК и VR устройства. 

Для доступа к игре необходима программа SteamVR.

## Требования к программному и аппаратному обеспечению
Для обеспечения работоспособности программы Тренажёр «Идентификация опасностей и инструктирование по охране труда» ПК должен обладать следующими характеристиками представлеными ниже:
* Операционная система:	Windows 10, Windows 11	
* Процессор:	Intel Core i5-4590/AMD FX 8350 или лучше	
* Оперативная память:	4 ГБ ОЗУ	
* Видеокарта:	NVIDIA GeForce GTX 970, AMD Radeon R9 290 или лучше	
* Сеть:	Широкополосное подключение к интернету	
* Поддержка VR:	SteamVR	
* Дополнительно:	1x USB 2.0 или новее, HDMI 1.4, DisplayPort 1.2 или новее	

Также, для работы с приложением необходим VR-шлем с контролерами для рук, поддерживающий подключение к SteamVR.

## Подготовка к работе
1.	Установка программы SteamVR.  
  1.1. Предворительно необходимо скачать и установить на компьютер сервис для распространения программ [Steam](https://store.steampowered.com/about).  
  1.2. Запустим Steam на компьютере.  
  1.3. Войдём в существующий аккаунт или зарегистрируем новый.  
  1.4. Далее необходимо найти в магазине бесплатное приложение [«SteamVR»](https://store.steampowered.com/app/250820/SteamVR/) и добавить приложение в свою библиотеку и установить, следуя инструкции.  
2. Подключение VR-шлема к ПК.  
  2.1. Предварительно необходимо загрузить и настроить драйвера для вашего VR устройства. Информацию о требуемых драйверах можно найти в инструкции к устройству или в сети интернет.  
  2.2. Далее требуется запустить клиент для подключения VR-устройства к компьютеру, включить VR-устройство и установить связь.  
  2.3. Ограничьте игровую зону для использования VR-шлема. Проверьте, чтобы никакие вещи не мешали вашему передвижению.  
3. Запуск тренажёра.  
  3.1. Скачать последнюю версию в [Releases](https://github.com/Nelliel2/VR-training-simulator/releases/)  
  3.2. Разархивировать скаченный файл.  
  3.3. Открыть папку с приложением и дважды кликнуть на файл «Тренажёр.exe».  
  3.4. После запуска программы автоматически должно запуститься приложение SteamVR. Подключите шлем и контроллеры к SteamVR. На рисунке ниже показано окно с подключенной гарнитурой.  
     <img width="254.5" height="150" alt="image" src="https://github.com/user-attachments/assets/c71bfe24-e1e4-4462-a9f5-accd67043b41"/>  

  3.5. Наденьте шлем виртуальной реальности и можете начитать использовать приложение.
  
## Описание операций
1. Передвижение. Передвигаться можно с помощью физического перемещения в рамках очерченной игровой зоны, или используя телепортацию. Чтобы использовать телепортацию, необходимо подвинуть джойстик в сторону, в которую вы хотите переместиться. Перемещая контроллер в пространстве, можно определить расстояние, на которое произойдёт перемещение, это можно отследить с помощью зеленого луча, зона доступная для телепортации подсвечивается при этом голубым цветом. Затем отпустите джойстик, чтобы телепортироваться на отмеченную точку.
<img width="638" height="325" alt="image" src="https://github.com/user-attachments/assets/2a6297f6-3964-4adf-b2a0-f93684a7f55e" />

2. Поиск объектов. Отметьте лазерной указкой все предметы, несущие в себе потенциальную угрозу. При наведении на объекты указка становится желтой. Нажатие на указку происходит с помощью верхнего курка правого контроллера. При нажатии узказки при наведении на объект, который не является угрозой, указка становится красной. При нажатии узказки при наведении на объект, который является угрозой, указка становится красной и начинается проигрываться сценарий, связанный с этой угрозой. 
<img width="861" height="334" alt="image" src="https://github.com/user-attachments/assets/94589096-3616-450e-a478-1096334e5c19" />

3. Результаты. При поднятии головы можно увидеть надпись, которая отражает сколько угроз обнаружено и прошедшее время с запуска приложения. 
<img width="455" height="130" alt="image" src="https://github.com/user-attachments/assets/4bce4004-fbe3-4512-812c-4584bec304f4" />

При нахождении всех угроз надпись окажется перед глазами, а время остановится.
